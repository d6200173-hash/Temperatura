# Conversor de Temperaturas

Aplicación web estática para convertir temperaturas entre Celsius, Fahrenheit y Kelvin.

## Ejecución local

1. Descomprime el proyecto.
2. Abre `index.html` en un navegador moderno.

No requiere instalación, servidor, backend ni dependencias.

## Estructura

- `index.html`: estructura semántica y accesible.
- `styles.css`: diseño responsive, colores y animaciones.
- `script.js`: validación y lógica de conversión.

## Despliegue

Sube los tres archivos principales a la raíz de un repositorio o servicio de hosting estático, como GitHub Pages, Netlify o Vercel.
